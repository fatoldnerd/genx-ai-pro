# GenX AI Pro Client Zero Input

## Business

GenX AI Pro is Brad Towers' applied AI consultancy. Its current website positions the business around practical AI adoption, workflow redesign, team enablement, and operating models. The immediate commercial goal is to package and sell a premium AI Agent Buildout Sprint.

## Starting condition

The following conditions were verified during the Client Zero work:

- The live GenX AI Pro website was deployed to Netlify from a Next.js project on Brad's MacBook.
- The website source was not under Git version control.
- Netlify had no connected Git repository and no retained source archive.
- A separate AI Agent Buildout Sprint Kit existed on the VPS but was not visible in Brad's normal workflow.
- The kit contains 51 workflow-agent packages and passes its deterministic validation script.
- GenX AI Pro did not have a domain-based business mailbox.
- There was no operating CRM for the Sprint offer.
- There was no organized Google Drive delivery workspace for the offer.
- Only one recurring automation existed, a weekly writing draft.
- Buyer-facing proof was scattered across source files, old demos, and internal documentation.

## Verified work completed

- Created the Google Workspace account `brad@genxaipro.com`.
- Added `hello@genxaipro.com` and `harvey@genxaipro.com` as aliases.
- Connected Gmail, Calendar, Drive, Docs, Sheets, and Contacts to Harvey through revocable OAuth.
- Created a GenX AI Pro Revenue Operations Drive hierarchy.
- Created and verified a three-tab AI Agent Buildout Sprint CRM with Prospects, Activity, and Pipeline views.
- Restored and verified the private GitHub repository for the 51-agent Sprint Kit.
- Curated buyer-facing, internal commercial, and demo assets into Google Drive.
- Secured Netlify API access without sharing Brad's password.
- Established dedicated SSH access from the VPS to Brad's MacBook.
- Located the original GenX AI Pro Next.js source.
- Verified that the existing source builds successfully on both the MacBook and VPS.
- Created a private GitHub source repository for the GenX AI Pro website.
