# GenX AI Pro consultancy platform

A responsive consultancy and coaching website for GenX AI Pro, built with Next.js and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Useful commands

```bash
npm run lint
npm run build
npm start
```

## Site structure

- `/` — business consultancy and team enablement
- `/coaching` — AI Office Hours and 1:1 session options
- `/tools` — readiness assessment, ROI calculator and course
- `/about` — founder story and point of view
